# 迷你倉主管分析圖

主管要在一張圖裡同時看「分店 × 時間 × 三個單位不同的指標」。Recharts 單軸塞不下，所以對比圖用 **D3 算尺度與形狀、React 畫 SVG**。

開工前先讀專案 `DESIGN.md`（顏色、字級、42px 輸入高度以它為準）。若有 `d3-data-visualization` skill，再讀它的尺度、標籤、SVG 筆畫規則。

## 誰做什麼

| 層 | 負責 | 不負責 |
| :--- | :--- | :--- |
| 資料層 | 欄位對應、空值、CWS 排除、月/季加總 | 配色、SVG |
| D3 | 尺度、面積層、上下兩層、直接標籤 | 業績公式 |
| React | 篩選、期間、分店選取、數字表 | 在 effect 裡重算業績公式 |

不重畫側欄、不輸出單檔 HTML artifact、**不產生假數字**：沒有匯入值就留空顯示「—」，不補 0，不拿現金實收冒充實收租金。

## 欄位與公式

Join 只用 `s_ino`。分店類型或店名含 CWS、或類型為共同工作空間，整列排除。

| 畫面 | 來源 | 空值規則 |
| :--- | :--- | :--- |
| 實收租金 | `store_perf_monthly.collected_rent` | 該月不畫點 |
| 已出租材積 | `store_perf_monthly.occupied_volume` | 該月不畫點 |
| 每材實收 | 實收租金 ÷ `rentable_volume`（沿用 `worksheet_compute.per_volume`） | 分母 ≤ 0 或任一欄空 → 空 |
| 可出租材積 | `rentable_volume` | 只當分母，不單獨成圖 |

**季度彙總**（放前端純函式並寫單測，例如驗證「4 不是 6.25」）：
- 實收租金：該季各月加總，空月略過，不當 0。
- 已出租材積：取該季**最後一個有值的月份**（存量不能相加）。
- 每材實收：只取實收與分母都有且分母 > 0 的月份，`Σ實收 ÷ Σ可出租材積`。**不要平均各月或各店的每材實收**；跨店合計同理。

圖下用一句話寫明「季度材積為季末值、每材為加總相除」。金額不寫 NT；業績達成率、出租率不進這張圖，也不拿來補空。

## 圖形編碼

- **單一序列**：同一月份軸，長條＝實收租金（左尺），淺色面積＋虛線＋白邊圓點＝每材實收（右尺），兩把尺都畫，數字直接標在標記上。
- **兩店以上**：改成上下兩層，左右邊距相同、月份對齊；點線只在下層，不疊回長條。**不畫第三條 Y 軸**，第三指標（已出租材積）放上方數字。
- 分店最多 5 間，同店長條與點線同色；超過時說明剩餘間數。
- 格線只跟長條的尺；缺值 `null` 讓線斷開；每個點跟自己的尺。
- 不把金額與每材實收正規化成 0–100。
- 顏色：Accent 只用 `#0B318F`；`#FFE100` 不畫線（白底看不清）；其他店色取深青、深琥珀、深玫紅、石板，對白底至少 3:1；不用紫色漸層。

## 版面（`data-od-id="mini-warehouse-compare"`）

1. 標題＋一句算法說明
2. 月份／季度切換（只這兩個選項）＋最多五店的顏色鍵
3. 所選期間三個合計；前一期兩邊都有值才顯示差額，否則「—」
4. D3 圖
5. 各店數字表（即圖的文字替代）

舊的區域長條、分店長條、倉型、新約保留在下方；它們回答單一指標排名，這張圖回答跨時間的三指標。

## 狀態與無障礙

| 狀態 | 畫面 |
| :--- | :--- |
| 載入 | 沿用頁面載入文案，逾時仍用同一句 |
| 空 | 「這個範圍還沒有匯入數字。」篩選保留 |
| 錯誤 | 「匯入數據沒有載入。」期間與已選分店保留 |
| 邊界 | 店名過長改到顏色鍵、X 軸不旋轉；某指標全空只在該面板寫「這欄還沒有數字」 |

- 期間可 hover，也必須有可鍵盤操作的 `<button aria-pressed>`；觸控不依賴 hover。
- SVG 給 `role="img"` 與描述三指標的 `aria-label`；細數放表格。
- 用 `:focus-visible`，不 `outline: none`；線條終點標店名，不只靠顏色區分。
- 不做路徑生長動畫，`prefers-reduced-motion` 直接畫最終狀態。

## 改程式時

- 月序列來自 `imported_dashboard._places` 的 `trend`，每列需帶 `collected_rent`、`occupied_volume`、`rentable_volume`、`revenue_per_volume`、`quarter`、`s_ino`。
- 公式或 CWS 規則改變時，同步更新本 skill 與專案的 `SESSION-HANDOFF.md`。

## ⚠️ Gotchas (避坑指南)

- **比率不能平均**：每材實收是比率，任何彙總都要「分子加總 ÷ 分母加總」，平均比率會得到錯誤值。
- **存量不能加總**：已出租材積是月底存量，季度取季末值；三個月相加會重複計算。
- **空值不是 0**：把缺月補 0 會讓趨勢線斷崖式下跌，主管會誤判業績崩跌。
