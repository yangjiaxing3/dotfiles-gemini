# 收多易 (Storeasy) 迷你倉庫 CAD 排櫃、物料尺寸與倉位編號規範

- 日期：2026-10-17
- 適用範圍：SketchUp / 空白建築 CAD 轉迷你倉庫自動排櫃規劃（`skp2cad`）與 AutoCAD 自動編號系統（`pyautocad`）

## 一、核心物理間距規則
1. **櫃子與櫃子之間的距離：固定為 `10 mm`（雙線獨立框）**
   - 包含左右相鄰倉位之間（`10 mm`）、背靠背倉位之間（`10 mm`）、以及主倉與後方加裝層板框之間（`10 mm`）。
2. **倉位離建築結構（外牆、內牆、壁柱、獨立立柱）的距離：`20 mm`**
3. **走道寬度鐵律：保留 `1300 mm` 寬以上，且越接近 `1300 mm` 越好（極限情況局部不得低於 `1200 mm`）**

## 二、標準物料尺寸模數表（單位：`mm`）
- **主倉固定面寬 $\mathcal{M}$**：
  - 雙門（`M`）：`1792`、`1492`（有效步進 `w + 10` = `1802`、`1502`）
  - 單門（`△`，長寬比 $D/W \le 2.0$）：`1000`、**`922`（單門優先採用）**、`772`（有效步進 `1010`、`932`、`782`）
- **寬度延伸部件（補件 $\mathcal{S}$，無三角形、不印「共用」文字，畫歸屬箭頭指自相鄰主件）**：
  - `692`、`642`、`592`、`542`、`492`、`442`（有效步進 `702`、`652`、`602`、`552`、`502`、`452`）
  - **⚠️ 核心物理定義（2026-10-20 糾正定案）**：
    - 圖面上的 `442 ~ 692`（寬度補件）與 `650 / 780`（深度補件）雖然在 2D CAD 圖面上畫成獨立格子，但那只是**工廠組裝同一個倉位的「鈑金部件（補件）」**，**絕對不是只有前半部分是倉位，也不是外掛的矮層板或獨立倉位**！
    - 例如 `1492×1100` + `1492×780` 組裝起來就是一個完整的 `1492×1880`（`1.5m × 1.85m`）倉位；若再加右側 `492×1100` + `492×780`（4 個部件框），組裝起來就是一個完整的 `1984×1880`（`2.0m × 1.85m`）一體成型大倉位！
    - 因此在 **3D 建模（`.skp` / `.glb` / `.html` / `.png`）與尺寸材積計算**中，必須將主件與其所有深度補件（`650/780`）及寬度補件（`442~692`）合併為**單一完整連通的 3D 倉位立方體**，嚴禁切碎成前半截主倉 + 後半截棕色層板/共用倉！
  - **歸屬配對鐵律**：
    1. 當寬度補件歸屬給單門主件（`772` 或 `922`）時，合併寬度 `w_main + 10 + w_shared` 必須 `< 1492 mm`；
    2. 較大寬度補件（`592 / 642 / 692`）僅能歸屬給 `1492 / 1792` 雙門主件；
    3. 每一排優先以純主件整數組合湊滿（**0 補件優先**），無法整除才放最多 1 格收尾寬度補件。
- **主件固定深度 $\mathcal{D}_{\text{main}}$**：
  - `1000`、`1100`、`1200`、`1450`、`1750`、`1900`、`2000`、`2100`（嚴禁出現 `1120` 等非標深度料號）。
- **深度延伸部件（補件）固定深度 $\mathcal{D}_{\text{ext}}$**：
  - `650`、`780`（在 2D 圖面上繪製為獨立部件矩形框，與前半部主件框之間隔 `10 mm` 雙線間距，但在實體與 3D 模型中與主件一體成型為同一個完整深倉位）。

## 三、從空白 CAD 直達最高平面得房率的「三階段確定性演算法」

### Stage 1：結構特徵投影與全域切齊基準線（Anchor Lines）鎖定
1. **結構退縮包絡線（Minkowski Inset `20 mm`）**：外牆內縮 `20 mm`、獨立立柱（`C1~Cn`）外擴 `20 mm` 建立禁放盒。
2. **鎖定柱列／出入口主基準線（綠色界線 $X_{\text{green}}$）**：切齊場內貫穿南北的立柱柱面與主出入口邊緣（如 `X = 17860`）。
3. **鎖定外圍壁櫃走道基準線（水藍色界線 $X_{\text{cyan}}$）**：西牆退縮 `20 mm` + 壁櫃深 $D_{\text{west}} \in \{1100, 1200\}$ + 走道 `1300 mm` = 水藍色界線（如 `X = 2520`）。
4. **雙界線雙向擴展**：兩界線內倉位對齊綠線後向左側水藍線擴展；綠線右側區域向綠線處擴展（保留 `1300 mm` 走道）。

### Stage 2：Y 軸深度 1D 切分與立柱包夾（Column-Wrapping）
1. **立柱包夾相位對齊**：將獨立立柱包入雙排背靠背中島內部，使中島中間的 `10 mm` 背靠背分界縫 $Y_{\text{seam}}$ 剛好貼齊立柱頂緣 `+20 mm` 或底緣 `-20 mm`（一排完整跨柱、一排於柱左/柱右分段，立柱 0 走道浪費）。
2. **合成深度超模數匹配**：組合單排深 $D_{\text{row}} = d + (10 + f)$ 與雙排中島深 $D_{\text{island}}$（如 `2210`、`2310`、`3660 mm`），使所有橫向走道全數落在 `1300 ~ 1340 mm`。

### Stage 3：X 軸跨距平移背包動態規劃（Shifted-Pitch 1D DP）
- 利用代數平移 $\tilde{L} = L + 10$、$\tilde{w}_i = w_i + 10$，消去 $(k-1)\times 10$ 間距耦合項：
  $$\sum_{i=1}^{k} (w_i + 10) = L + 10$$
- **尾數同餘定理（Modulo-10 Invariant）**：除 `1000`（步進 `1010`）外，所有主倉與共用倉步進寬度尾數皆為 `2`（$\equiv 2 \pmod{10}$）。只需在走道彈性視窗 $\delta_L \in [0, 20]\text{ mm}$ 內微調，即可在 `< 1 ms` 內找出 **0 畸零、100% 命中標準物料表** 的最高坪效組合。

## 四、倉位編號與「倉位編號引導線」完整規範（萃取自 `pyautocad` 與 `倉位含編號test.dwg`）

### 1. 哪些框體要編號？哪些不編號？（箭頭合併前處理）
- **僅「主倉位」賦予獨立編號**：
  - 凡是有紅/洋紅**指向箭頭（Merge Arrow，長度 `< 1000 mm`）**相連的子框體——包含**後方加裝層板框（`650 / 780 mm`）**與**側面收尾共用倉（`442 ~ 692 mm`）**——在邏輯上皆與箭頭起點之主倉合併為同一租賃單元（`merge_adjacent_spaces`）。
  - **共用倉與層板框絕對不編獨立號碼**，引導線（`TRUTH_ROUTE` / `PREDICTION_ROUTE`）直接跳過共用倉與層板框，只串聯有門向三角形（`△` / `M`）的主倉中心點。

### 2. 「倉位編號引導線（Route Polyline）」走道巡迴五大法則
根據 `倉位含編號test.dwg`（圖層 `TRUTH_ROUTE` 紅線）與 `pyautocad` 演算法：
1. **起點錨定法則**：
   - 從**主入口進門處第一排靠牆倉位**（通常為右上角或右下角入口側最外圍靠牆排，如 `HD1 ~ HD6`）開始起算第 1 號。
2. **單一走道 U 型迴轉法則（Aisle U-Turn Traversal，嚴禁穿牆跳躍）**：
   - 編號動線模擬「**人實際走在走道裡看門牌**」的順序，**絕對禁止跨越背靠背隔板跳到隔壁走道**：
     - **去程**：進入一條走道後，先沿走道其中一側（例如北側排，門朝下向該走道）從頭走到尾連續編號（如 `HD7 -> HD15`）；
     - **U-Turn 折返**：走到該走道盡頭後，**直接跨過這條走道到正對面排**（南側排，門朝上向同一條走道），反方向從尾走回頭連續編號（如 `HD16 -> HD27`）！
3. **封頭櫃與靠牆櫃順向銜接法則（End-Cap & Wall Bridge）**：
   - 完成一條走道的去回程 U 型巡迴回到走道出口後，順著**中島端部封頭櫃（End-Caps）**或**外牆靠牆櫃**（如 `HD28 -> HD31`、`HD67 -> HD70`）由北往南滑入下一條相鄰的平行走道，繼續下一個 U 型巡迴（`HD32 -> HD42` 去程、`HD43 -> HD66` 回程）。
4. **分區推進法則（先橫向主區、後縱向次區、最後邊角區）**：
   - 若全場包含不同走向的區域（如東半部為橫向走道、西半部為縱向走道、南側底部為外圍長廊），引導線先跑完主入口所在的橫向走道群，再順接進入縱向走道群（同樣遵循「東側由下往上 `HD130->137` $\to$ 頂端 U-Turn $\to$ 西側由上往下 `HD138->146`」），可由 1 條或分段 2 條 `ROUTE` 聚合線串接全場。
5. **雙模式演算法支援（Polyline 投影排序 vs. 自適應慣性巡迴）**：
   - **模式 A（有引導線 `ROUTE` Polyline）**：計算各主倉中心 $(c_x, c_y)$ 在引導線上的正交投影累積弧長 `accumulated_dist_along_route` 進行排序（`assign_sequence_by_route`）。
   - **模式 B（無引導線自動生成 `Adaptive Inertia TSP`）**：以 $\text{Cost} = \text{dist}^2 \times 100^{(1 - \cos\theta)/2}$ 對 90° 轉彎施加 10 倍懲罰、對 180° 倒退施加 100 倍懲罰，自動沿同排直線走到底才 U-Turn 轉彎，並自動繪出 `PREDICTION_ROUTE` 引導線。

### 3. 編號格式、上下層對位（`D` / `U`）、跳號、字體方向與高度顏色映射
- **上下層對位編號鐵律（`{店碼}D` 下層 vs. `{店碼}U` 上層同號對位）**：
  - 倉位前綴由 **「1 碼分店代號（如 `M`、`T`、`Z`、`C`）+ 1 碼樓層屬性（`D` 或 `U`）」** 組成：
    - **`{店碼}D`（Down，下層或單層平面號）**：平面圖上所有主倉位皆由 `{店碼}D` + 起始流水號起編（例如從 **`MD1700`** 開始：`MD1700, MD1701, ...`）。
    - **`{店碼}U`（Up，上層對位號）**：凡屬性標註為 **`雙`（雙層倉）** 的倉位，其正上方的上層倉位**直接採用與下層完全相同的流水號，僅將前缀 `D` 改為 `U`**（例如下層為 `MD1706`，其正上方對位的上層倉位即為 **`MU1706`**；若為 **`單`（單層高櫃）**，則僅有 `MDxxxx`，無對應之 `MUxxxx`）。
- **禁忌號碼跳號（`exclude_list`）**：支援自動跳過傳統忌諱號碼（`pyautocad` 預設排除 `["004", "013", "044", "444", "4444"]`）。
- **文字放置位置與旋轉角度**：
  - 置於**主倉框幾何正中央**（`Alignment = 10` Middle-Center）。
  - **旋轉角度**：依倉位方向或門向決定——直立窄長倉（$H > 1.2 W$，門朝左/右）文字旋轉 `90° / 270°` 打直；橫向倉（門朝上/下）文字水平 `0°`（或在 `倉位含編號test.dwg` 中依讀者面向門方向設為 `0°` 與 `180°`）。
- **CAD 圖層顏色與單/雙層高度映射表（`COLOR_MAPPING`）**：
  - `3 (綠)` $\to$ `單 2300 mm` | `8 / 251 (灰)` $\to$ `單/雙 2000 mm` | `6 (洋紅)` $\to$ `半 2800 mm`
  - `5 (深藍)` $\to$ `雙 3200 mm` | `4 (水藍)` $\to$ `雙 3300 mm` | `2 (黃)` $\to$ `雙 3400 mm`
  - `30 (橘)` $\to$ `雙 3600 mm` | `7 (白)` $\to$ `雙 4000 mm`

## 10. 立體淨高 ($Z$) 對應倉位高度 ($H$) 與營業尺寸/材積計價對位鐵律（2026-10-17 實證定案）

### 1. 現場樑下/樓板淨高 ($Z$) 與「單層 / 半層 / 全高雙層」連動設計規則
1. **單層倉（`單`，高度固定 `2300 mm` = `2.3 m`）**：
   - 僅有下層編號 `MDxxxx`（無 `MUxxxx`）。
   - 適用於：加裝深層板之大深度單層櫃、或上方淨高不足以做全高雙層（如 `Z = 2620~3350 mm`）且深度 $> 1000\text{ mm}$ 之倉位。
2. **半層倉（`半`，總高 `2800 mm` = 下層 `1400 mm (1.4 m)` + 上層 `1400 mm (1.4 m)`）**：
   - 具備下層 `MDxxxx`（高 `1.4 m`）與正上方同號對位上層 `MUxxxx`（高 `1.4 m`）。
   - **觸發條件**：
     - 當上方樑下高度為 **`2950 mm`**（或 **`3350 mm`** 等 $< 3800\text{ mm}$ 區域），且**倉位深度設計為 `1000 mm`（`1.0 m`）**時，即可規劃為上下各 `1.4 m` 的「半層倉」！
     - **⚠️ `3350 mm` 淨高限制**：在 `Z = 3350 mm`（及 `2950 ~ 3350 mm`）區域，因總高未達 `3800 mm`，**只能做「上下 `1.4 m` 半層倉（需搭配 `1000 mm` 深度）」或「`2300 mm (2.3 m)` 單層倉」**，不可做 `2000 + 1800` 的全高雙層倉。
3. **全高雙層倉（`雙`，總高 `3800 mm` = 下層 `2000 mm (2.0 m)` + 上層 `1800 mm (1.8 m)`）**：
   - 當上方淨高達到 **`3800 mm`** 時，標準雙層配置為：
     - **下層 (`MDxxxx`)**：高度 **`2000 mm` (`2.0 m`)**
     - **上層 (`MUxxxx`)**：高度 **`1800 mm` (`1.8 m`)**

### 2. CAD 工程尺寸 (`mm`) $\rightarrow$ 營業計價尺寸 (`m`) 轉換公式（以 `0.05 m` 為級距）
- **面寬 $W$ 轉換**：
  - 雙門主倉：`1492 mm -> 1.5 m`、`1792 mm -> 1.8 m`
  - 單門主倉：`772 mm -> 0.75 m`、`922 mm -> 0.9 m`、`1000 mm -> 1.0 m`
  - **主倉 + 共用倉合併寬度**：共用倉不獨立編列倉位號，直接將寬度併入歸屬主倉計價（`442 -> +0.45m`、`492 -> +0.50m`、`542 -> +0.55m`、`592 -> +0.60m`、`642 -> +0.65m`、`692 -> +0.70m`；如 `922+442=1364mm -> 1.35m`、`772+442=1214mm -> 1.2m`）。
- **深度 $L$ 轉換**：
  - 純主倉深度：`1000 -> 1.0m`、`1100 -> 1.1m`、`1200 -> 1.2m`、`1450 -> 1.45m`、`1750 -> 1.75m`、`1900 -> 1.9m`、`2000 -> 2.0m`、`2100 -> 2.1m`。
  - 主倉 + 層板組合深度：`1100+650 (1750/1756mm) -> 1.75m`、`1100+780 (1856/1880mm) -> 1.85m`、`1436mm -> 1.45m`、`1656mm -> 1.65m`、`2106mm -> 2.1m`、`2406mm -> 2.4m`。
- **材積與租金公式**：
  - $\text{面積} = W_{\text{m}} \times L_{\text{m}}$；$\text{實際容積} = W_{\text{m}} \times L_{\text{m}} \times H_{\text{m}} + \text{增減數值}$
  - $\text{實際材積} = \text{實際容積} \times 35.3146$；**$\text{最後材積} = \text{MROUND}(\text{ROUNDDOWN}(\text{實際材積}, 0), 5)$**（先無條件捨去小數點，再以 `5 才` 為倍數四捨五入，即 `((int(math.floor(raw_cai)) + 2) // 5) * 5`）
  - $\text{月租表價} = \text{ROUND}(\text{最後材積} \times \text{每才單價}, -1)$（季繳 95 折、半年 9 折、年繳 85 折/8 折皆四捨五入至十位數）。

## 11. 新據點上下層定價優化黃金法則與跨區域定價 SOP（2026-10-18 實證定案）

### 1. `[Anti-Pattern 錯誤模式]`（嚴禁重蹈覆轍之三大定價盲點）
1. **❌ 盲點一：誤拿「同才數（跨不同底面積櫃位）」去算上下層價差 %，而非「同櫃位對位 (`{店碼}Dxxxx` vs `{店碼}Uxxxx`)」**
   - 在雙層櫃中，下層高度較高（`1.5m` 或 `2.0m`）、上層高度較矮（`1.3m`、`1.4m`、`1.55m` 或 `1.8m`），同底面積下層才數必大於上層（例如下層 `155 才` vs 上層 `105 才`）。
   - 若誤拿「`105 才上層` vs `105 才下層（底面積較小之高單價櫃）`」計算價差，會把「小櫃體本身的級距溢價（約 `4% ~ 5%`）」重複算進上層折扣裡，使真實的 **`-14% ~ -16.5%`** 同櫃價差被假性放大為 **`-19.5% ~ -25.0%`**。
2. **❌ 盲點二：跨全系統無差別平均，混入早期舊店（中和一/二/三店 `-28%~-33%`、三重湯城 `-25%~-29%`）之極端折價**
   - 不同生活圈與店齡的上下層折價結構差異極大；嚴禁將新北早期工業/舊式雙層店的極端折扣混入桃園或台北市核心區新據點。
3. **❌ 盲點三：在基準店（如中壢店）較低的下層單價上，又套用鄰店失真放大的折價率（Double-Dipping 雙重打折）**
   - 當基準店本身無完整上層（如中壢店僅有 45/50 才上層）而需借鏡同區有上層之鄰店（如平鎮新富店、桃園南崁店）時，若未考慮基準店下層單價原本已低於鄰店 `0.6 ~ 1.0 元/才`，直接乘上過大折價率會導致 `80 才` 以上上層單價跌破跨區底線（如低於三重、淡水）。

### 2. `[Correct-Pattern 正確作法]`：新據點（含上下層）五步定價標準 SOP
1. **Step 1：鎖定「同行政區 / 同生活圈」之錨定基準店（Anchor Stores）**
   - 優先選取同行政區或相鄰生活圈內 **具備完整上下層規格** 之分店群作為錨定群（例如：桃園中壢區錨定 **中壢店 + 平鎮新富店 + 桃園南崁店**；台北市松山區錨定 **松山一～四店 + 中山八德店 + 內湖/南港二店**）。
2. **Step 2：建立「下層 / 單層 (`D`)」基準每才單價曲線（隨才數嚴格單調遞減）**
   - 從資料庫 `storage_inventory` 撈出錨定店 `st_cat_name = '下層'` 各才數（`35 才 ~ 450+ 才`）之實測 `price_per_unit`。
   - 注意區分「半層之下層（`H = 1.4~1.5m`，多集中在 `45~70 才`，每才單價較高）」與「標準單層（`H = 2.3m`）/ 全高雙層之下層（`H = 2.0m`）」。
3. **Step 3：以「同櫃號上下對位 (`{店碼}Dxxxx` vs `{店碼}Uxxxx`)」萃取真實上下層單價差 %，並直接貼齊同區鄰店上層實測價格帶**
   - 使用正則 `^[A-Z]([DU])(\d+)$` 配對同櫃位上下層，計算真實同櫃單價差：
     - **桃園區（平鎮新富、桃園南崁、桃園春日）**：同櫃上下層價差穩定落在 **`-14.1% ~ -16.6%`（平均 `-15.7%`，即約 84~85 折）**；上層單價直接貼齊平鎮/南崁實測值（`40才=21.0, 50才=19.6, 55才=19.5, 60才=18.8, 65才=18.6, 75才=18.4, 80~85才=18.1, 95~100才=17.6, 105才=17.2, 130~135才=16.6, 150才=15.9, 155才=15.7, 175~180才=15.3`）。
     - **台北市核心商業區（松山一～四店、中山八德店、內湖店、南港二店）**：
       - 中小型上層（`40~85 才`，對應下層 `55~130 才`）：同櫃上下層價差約 **`-12.5% ~ -15.0%`（約 85~87 折）**。
       - 中型上層（`90~145 才`，對應下層 `135~200 才`）：同櫃上下層價差約 **`-15.0% ~ -18.5%`（約 82~85 折）**。
       - 大型上層（`150~250 才`，對應下層 `210~350 才`）：因高處搬運大型物件難度增加，同櫃價差溫和擴大至 **`-19.0% ~ -23.0%`（約 77~81 折）**。
4. **Step 4：執行「跨區域價格階層防線（Cross-Region Hierarchy Guardrail）」檢核**
   - 確保全級距（特別是 `80 才` 以上中大倉）之上層與下層每才單價嚴格符合收多易區域行情排序：
     $$\text{台北市核心區（大安/信義/松山/中山）} > \text{台北市外圍與竹科（內湖/士林/南港/新竹）} > \text{新北核心區（板橋/中和新店/永和）} > \text{桃園核心區（平鎮/南崁/春日/中壢）} > \text{新北蛋白區（三重/淡水）}$$
   - 任何一個才數點位若出現「高價區上層 $<$ 低價區上層」（例如桃園上層低於三重/淡水，或松山區上層低於板橋/三重），立即標記為異常並拉回同區實測曲線。
5. **Step 5：執行「月租表價單調遞增（Strict Monotonicity）」終審門禁**
   - 計算每個才數 $C$ 的月租表價 $M(C) = \text{ROUND}(C \times P(C), -1)$，強制驗證當 $C_2 > C_1$ 時，$M(C_2) > M(C_1)$ 且 $P(C_2) \le P(C_1)$，杜絕「大倉月租反而比小倉便宜」的价格倒掛。

## 八、頂視圖（Top View）倉號呈現、合併倉一體化與內包樑柱容積扣減規則（2026-10-21 確立）

   - **唯一例外**：只有當使用者在右側「圖層顯示」中**單獨打勾「只顯示上層」**或**單獨打勾「只顯示下層」**時，頂面才切換顯示 `MUxxxx` 或 `MDxxxx`。
   - 頂面字體支援 **Zoom-in / Zoom-out 三段式自適應縮放（LOD）**：拉遠鳥瞰時自動放大純數字並隱藏次要小字；拉近特寫時自動呈現完整尺寸與才數/月租。
2. **「合併倉」與「單門＋側板」在 Top 頂視圖必須呈現為單一完整倉位**：
   - 不論是「單門＋黃色側板（避樑倉）」或「深度/寬度延伸合併倉」，在 Top 正上方俯視圖中**一律算作同一個完整倉位**，頂面必須是**單一完整底色與單一外框，文字置於整個合併倉位的正中央**，**絕對不能因為樑柱包在側板裡面就把頂面切成左右兩半**（黃色側板僅呈現在 3D 正面門板旁）。
3. **內包樑柱倉位的計費材積扣減規則（「完整尺寸容積 − 樑柱容積」）**：
   - 凡是倉位內部包入結構大樑或立柱（如「單門＋側板」將大樑包在側板區內之上層倉 `MU`），其計費容積一律以**「完整外框尺寸（寬 × 深 × 高）的總容積，減去該倉位內被樑柱穿過佔用的容積（`beam_deduct_m3`）」**計算：
     $$\text{實際容積 } (\text{m}^3) = (\text{完整寬 } W \times \text{完整深 } L \times \text{高 } H) - \text{樑柱佔用容積}$$
   - 同步寫入 Excel 總表之 `主管設定價格` Sheet（第 E 欄 `增減區域 = "-扣樑柱"`、第 F 欄 `增減數值 = -beam_deduct_m3`）以及 3D 報價明細卡。
