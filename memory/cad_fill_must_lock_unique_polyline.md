# CAD 色塊必須鎖在唯一黑框上

- 日期：2026-09-17
- 專案：STOREASY_IT / 新生南店 s_ino=69 / 563、502

## Anti-Pattern

色塊從「文字插入點 + 典型倉高 + 鄰居對齊」推，而不是從使用者看見的黑框來。

後果：
- 563 圖層 0 加高單倉（框內只有 563）被 `_is_structural_bay_frame` 當結構灣丢掉，再退化成文字底部的 60×40 小格。
- `_snap_orphans_to_neighbor_rows` 對**已經對上黑框**的倉再跑一次，把正確框覆寫成鄰居矮格。
- 為修 502 走道而加的啟發式，會誤傷真實加高單倉。

## Correct-Pattern

1. polyline 框內只有一個倉位號 = 可見黑框。鎖定，禁止丟、禁止 snap。
2. 上下兩個空心 U（hits=0）左右對齊、中間夾一個編號時，色塊填聯集。新生南 502 的黑框不是封閉矩形，編號在開口裡。
3. 多號共用外框（hits≥2）若被貫穿分隔線切開，子框只含一號就鎖定。新生南 ND540 編號在上排 C 框右格，色塊卻被鄰居複製到 ND541 旁邊。
4. LINE 拼框才過濾結構灣（走道編號不能吃整列）。
5. 鄰居／夾縫啟發式只處理**沒對到唯一框**的倉。
6. 品質門檻：`text_outside_fill`（編號落在色塊外）與 60×40 fallback、重疊並列。
7. `--reload` 偵測到檔案變更不代表 worker 已重載；重匯入前必須確認 8005 worker 啟動時間晚於 `cad_service.py`。
