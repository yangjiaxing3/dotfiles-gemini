# 合約與正式單據範本 100% 原檔還原鐵律 (100% Fidelity to User-Provided Document Templates)

## [Anti-Pattern 錯誤模式]
- 當使用者提供歷史合約或單據正本（如 Dropbox 內的 `.docx` 增補合約書：`智能櫃系統維護增補合約_新竹_中華店二期.docx`）要求系統產生預覽與歸檔檔案時，未先拆解原檔內部 XML 段落、編號階層與表格結構，就憑空「美化」版面（例如加上 `#1B4636` 綠色卡片框、頂部綠線、把 `壹、貳、` 改成 `1.`、把 `五、`/`六、` 併排、在地址前亂加 `【店名】`、或自行編造錯誤的甲乙方代表人/統編/地址）。

## [Correct-Pattern 正確作法]
1. **強制先拆解原檔結構**：凡涉及產生合約書、增補合約、報價單、請款單等正式文件，必須先讀取使用者指定之最新正本檔案（如 `.docx` 之 `word/document.xml` 與 `word/numbering.xml`），逐段列出文字、字體、字級、粗體/底線、對齊方式與編號格式。
2. **100% 逐字、逐階層、逐版面還原**：
   - 預覽畫面 (`HTML`) 與匯出檔案 (`PDF` / `DOCX`) 必須與原檔 **100% 一致**，嚴禁自行增刪文字、改變條號階層（如原檔為 `一、` 搭配縮排獨立行 `壹、`、`貳、`，絕不可改為同行 `1.`）或添加原檔沒有的裝飾性框線與顏色。
   - 立約書人（甲方、乙方、統編、地址、負責人）必須 100% 採用原檔真實記載之公司資訊，嚴禁臆測或套用其他不相關資料。
